# Pop Art Color Themes para VS Code ⚡🎨

Una colección de temas oscuros vibrantes y de alto impacto gráfico para VS Code, inspirados en los grandes maestros del **Pop Art**: **Andy Warhol**, **Roy Lichtenstein** y **Keith Haring**.

---

## Las 3 Variantes

### 1. Pop Art - Warhol Dark (Vinyl Pop) ★

- **Fondo:** `#1A1824` _(Dark Vinyl)_
- **Inspiración:** Las serigrafías de Marilyn, latas Campbell y flores eléctricas.
- **Paleta:**
  - **Keywords:** `#FF2A6D` _(Pop Magenta / Neon Pink)_
  - **Funciones:** `#FFE600` _(Amarillo Canario Eléctrico)_
  - **Strings:** `#00F59B` _(Menta Neón / Verde Serigrafía)_
  - **Tipos & Clases:** `#00D2FF` _(Cian de Proceso)_
  - **Números & Booleans:** `#FF9233` _(Naranja Jugoso)_
  - **Operadores:** `#C77DFF` _(Ultravioleta)_
  - **Texto Base:** `#F4F6FB` _(Blanco Satinado)_

### 2. Pop Art - Lichtenstein (Comic Primaries)

- **Fondo:** `#161922` _(Tinta de Viñeta)_
- **Inspiración:** Las viñetas de cómic y los puntos Ben-Day clásicos.
- **Paleta:**
  - **Keywords:** `#FF384B` _(Rojo Cadmio Cómic)_
  - **Funciones:** `#FFDE00` _(Amarillo Puro Ben-Day)_
  - **Strings:** `#28E088` _(Verde Lima Gráfico)_
  - **Tipos & Clases:** `#3894FF` _(Azul Cobalto Imprenta)_
  - **Números & Booleans:** `#FF851B` _(Naranja Pulp)_
  - **Operadores:** `#D154FF` _(Violeta de Acción)_

### 3. Pop Art - Keith Haring (Electric 80s)

- **Fondo:** `#171620` _(Noche Arcade)_
- **Inspiración:** Los dibujos radiantes con tiza en el metro de Nueva York en los 80s.
- **Paleta:**
  - **Keywords:** `#FF3E8A` _(Rosa Chicle Radiante)_
  - **Funciones:** `#FFB703` _(Oro Radiante)_
  - **Strings:** `#70FF00` _(Lima Ácida Subway)_
  - **Tipos & Clases:** `#00F0FF` _(Cian Neón Radiante)_
  - **Números & Booleans:** `#FF6B35` _(Naranja Tiza Vivo)_
  - **Operadores:** `#B5179E` _(Magenta Arcade)_

## Instalación en VS Code

Ejecuta el script de instalación dentro del directorio:

```bash
cd pop-art-theme
./install.sh
```

O enlázalo manualmente:

```bash
mkdir -p ~/.vscode/extensions
ln -sfn "$PWD" ~/.vscode/extensions/pop-art-theme
```

### Activación

1. Presiona `Cmd + Shift + P` y ejecuta `Developer: Reload Window`.
2. Presiona `Cmd + K` y luego `Cmd + T`.
3. Selecciona cualquiera de las variantes de **Pop Art**.
